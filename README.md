# ENGLISH POCKET EXAM — version simple

500 questions : 250 de grammaire et 250 expressions professionnelles. Quatre choix, correction immédiate, indices, traduction et explications. Accès direct sans compte. Pas de statistiques, de notes, de points ni de gestion de classes.

Les réponses sont conservées uniquement dans le navigateur. Les sauvegardes locales précédentes peuvent être reprises explicitement, sans mélange automatique. Les anciennes données serveur ne sont pas supprimées, mais ne sont plus consultées par cette version.

Construction du site : `npm run build`. `node scripts/build-simple.mjs` permet aussi de préparer les fichiers statiques du quiz. Les anciennes routes de compte, professeur, classe et API ont été retirées.
